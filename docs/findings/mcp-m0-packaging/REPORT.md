The baseline's 300 ms cold-init limit includes collector setup and worker initialization in one boundary; the Python split timings do not establish compliance. Its 170 ms query limit covers a multi-case trace matrix, not the one type-error workload here. Its 129 MiB cgroup memory-charge limit is not comparable to separate VmHWM readings. Allocation, retained heap, comparable process-tree memory, archive/build/download costs and a matched trace comparison were not measured. The baseline budgets remain unchanged; no budget pass, performance winner or macOS result is inferred.

## Required next experiment

In a bounded Linux follow-up, extend the Python experiment with a deliberately nonresponding worker and a finite deadline: verify a terminal error, continued status/other-workspace service, termination and reaping, including replacement during an outstanding request. Add a worker-origin identity mechanism with explicit trust assumptions, then test changed compiler and stdlib bytes, stale/replaced artifacts, and two worktrees with distinct compiler edits; require matching claims only when attested identity and complete snapshot/profile identity agree. Keep baseline results explicitly labeled. Repeat the existing corrupt/missing/version and fake-worker controls. Measure the pinned baseline's exact cold-init, multi-case query and cgroup-memory boundaries with the same harness, reporting all failures and dependencies. If the mechanism or bounded lifecycle cannot be demonstrated, leave Python disqualified and evaluate a separately scoped alternative rather than selecting it by fiat. Then run the deferred actual macOS experiment under #4820 before a cross-platform decision.

The [private protocol](../../design/MCP-WORKER-PROTOCOL.md) describes proposed negotiation, request and replacement behavior; it is not evidence that either candidate implements the full contract. Existing MCP clients and wrapper behavior remain available until a separately implemented, documented migration preserves compatibility. M1 module ownership and issue updates await a qualifying decision.
