# Linux installed supervisor experiments

On Linux 6.12.95+deb13-amd64 x86-64, a KVM guest with 12 logical CPUs and AMD EPYC 9645, five sequential sessions of each installed candidate ran under Linux seccomp. The Python supervisor delegated a real type-error check to the pinned compiler in all five sessions; the Medaka executable instead reported that live bidirectional worker supervision is unavailable in all five. An exit status of zero from that executable is not success for the required capability. These are experiments, not qualifying production supervisors. macOS is deferred to #4820.

Python 3.13.5 and its standard library are required by the Python candidate. The supervisor and pinned compiler dynamically linked libc and libm on this host; Boehm GC 8.2.8 was installed, and clang 19.1.7 was used to compile the Medaka prototype. The installed Python and Medaka trees occupied 24,630,537 and 24,818,152 bytes respectively (`du -sb`, including directory sizes; excludes system Python and libraries). The unchanged baseline distribution archive SHA-256 was `8e4167a0ce27aac59cb9a37225360ba28b48016e34621a775da9e1a82f213225`; its compiler was `4b05aab61552d290a0e33d2b6f2f825290ecc61e24d9138f7fbaa829a19ee503`, the Medaka supervisor `f90a732704daae392ab89bccd84d2380af16aabf5015c31b5218a4c037b11d59`, and Python supervisor `8cad021f2d06a727a0bf5f6051fa2325ee140160457da56bb772a484e9d737c6`. Hashes are inferred artifact identity, not worker attestation.

The [raw observations](linux-x86_64-raw.json) preserve all timings and process measurements. Python launch to supervisor initialize was 74.45–126.96 ms, then opening and initializing the worker took 70.60–128.54 ms. The first semantic check took 20.02–28.65 ms; the 25 warmed checks took 10.08–34.66 ms each, an aggregate 49.05 checks/s calculated as 25 divided by their total serial round-trip time. Medaka launch to its unavailable message took 11.28–41.61 ms; it has no query or throughput result. Installation copies took 70.26 ms for Python and 58.99 ms for Medaka in this run. Archive creation, compilation and downloads were not timed; no download occurred during these offline sessions.

Python supervisor and worker `/proc/PID/status` VmHWM values were sampled separately after the sixth query: 32.50–32.71 MB and 75.75–77.18 MB. These independent high-water marks are not a simultaneous sum or a process-tree peak. Per-session child CPU (supervisor and its reaped worker, excluding the measuring process) was 120.45–152.01 ms user plus system. Allocation and retained heap were not measured. The sprint 2 129 MiB budget measures private cgroup memory charge, including namespace and descendants; VmHWM is not comparable. The sprint 2 startup budget includes collector setup and worker initialization in one measurement; these split timings have a different boundary. Its 170 ms query budget covers a distinct multi-case trace matrix, so the present single type-error workload does not establish compliance with that matrix.

Reproduce with `python3 scripts/mcp_bench/prototypes/report.py <extracted-baseline-bundle> <compiled-supervisor> <empty-install-directory> > linux-raw.json`. The supplied bundle comes from `sh scripts/make_dist.sh <output-directory>` in the pinned baseline tree; compile the prototype with that baseline compiler. The script assembles independent copies and applies the inherited seccomp filter to each launched process. A control running `socket.socket()` under the same filter exited 1 with `PermissionError: [Errno 1] Operation not permitted`. At the measured revision, the prototype gate additionally exercised replacement of a rebuilt compiler while connected, error and missing artifacts, worker exit, and direct-worker shutdown reaping; it did not test descendant cleanup or canonical root aliases. The Python prototype still lacks a scheduler, bounded stuck-read timeout and worker attestation; matching and complete workspace identity are unavailable. The Medaka candidate fails live lifecycle outright. Successful ordinary cleanup is not evidence that stuck reads can be bounded.

A subsequent repair tests same-group child cleanup, including an exited direct worker, but detached descendants and process-group escape remain unresolved. These measurements were not rerun at that revision.
