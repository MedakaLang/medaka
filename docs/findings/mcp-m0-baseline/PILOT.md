# Agent pilot

The denominator is 12: one attempt for each of six tasks in each arm, run serially with alternating arm order. These are individual pilot observations, not population estimates. The [machine-readable rows](pilot-results.json) retain every criterion and control, its task basis, judgment, rationale and evidence digest. A host completion is not a correctness grade: six rows pass all criteria, and six contain at least one failed criterion. No retries or budget denials occurred.

Both repair agents proposed the correct source but reported a read-only workspace; the retained workspace hashes confirm that the original file remained. Neither established the requested result on the repaired file. The worktree answers omit the required stdlib identity check and strict freshness setting. Both filter answers correctly identify the API and re-export, but claim `list.filter` becomes available from a bare import; bare imports bind no names. MCP reference queries in the import task returned empty arrays, and the MCP dispatch query returned a generic signature. Shell was used in these trials; the observations do not establish the agent's causal reason for using it. Two MCP-enabled trials used no MCP operations at all. The result records retain per-tool counts instead of inferring successful MCP use.
