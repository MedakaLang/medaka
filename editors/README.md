# editors

Editor support for `.mdk` files. `vscode-medaka/` is the VS Code extension (TextMate grammar
plus a client for `medaka lsp`); `install-vscode.sh` copies it into VS Code's and Cursor's
extension folders. The tree-sitter grammar lives beside it at `../tree-sitter-medaka`. See
`vscode-medaka/README.md` for features and settings.
