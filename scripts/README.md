# scripts

Repository tooling, not part of the language. `pr.sh` is the pull-request helper
(`docs/ops/PR-HELPER.md`); `sprint-*.sh` and `sprint-cost-report.py` support the agent sprint
workflow described in `AGENTS.md`; `make_dist.sh` builds a release tarball; `docker-dev.sh`
and `medaka-mcp-wrapper.sh` are developer conveniences; `ci_shard_cost.sh` and
`cost_baseline_land.sh` maintain the CI gate-cost baseline; `jev/` is an experiment harness
with its own README.
