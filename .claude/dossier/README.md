# `.claude/dossier/` — the incident narrative behind AGENTS.md

`AGENTS.md` is loaded into **every** agent session in this repo (via `CLAUDE.md`). That made its
size a per-session tax, so on 2026-08-17 it was compressed from ~102KB of teaching prose into a
router of ~25KB: trigger → rule → remedy command, one line or two per item.

**The prose was not deleted. It moved here.** Every item in `AGENTS.md` that had a story behind it
carries a bracketed ID and a link into one of the files below.

| File | Covers |
|------|--------|
| `pipeline.md` | Stage order, desugar-runs-first, import/export forms, the doctest module-identity residual |
| `workflow.md` | Branch protection, the merge queue, required checks, shard costs, the backlog and the severity ladder |
| `build.md` | `make medaka`, the staleness guard, emitter borrowing, the environment and the dual-platform invariant |
| `gates.md` | `make preflight`, the gate suite, oracle staleness, golden capture, the must-fail tracker |
| `tooling.md` | The pre-commit hook, `fmt`/`lint`/snapshot blessing, and every `.mdk` debugging probe |
| `traps.md` | The Traps section, dogfooding, writing tests, the shell-gate traps, and the skill table |

## Why here and not `docs/ops/`

`test/check_agent_doc_symbols.sh` gates `AGENTS.md`, `.claude/skills/*`, `.claude/workstreams/*`
and this directory at its BROAD tier — every backticked symbol is a claim that must resolve
against real source. `docs/ops/*.md` is **not** a member of that corpus. Extracting the prose to
`docs/` would have silently dropped it out of the symbol-rot gate on the way out; the prose did not
change character by moving, so its gating should not either. `docs/README.md` is also generated by
`make docs-index` from a `**Status:**` banner, which this material does not want.

## How to use it

**You should rarely need to.** `AGENTS.md` keeps the trigger, the rule, and the remedy command for
every item — an agent who never opens this directory must still act correctly, and that is a
requirement on `AGENTS.md`, not a hope. Come here when you want to know *why* a rule is shaped the
way it is: what went wrong, how it was measured, and which previously-confident sentence turned out
to be false.

If you find yourself needing a **command** from here that `AGENTS.md` did not give you, that is a
bug in the compression — fix `AGENTS.md`.
