ROW IDENTITY, NOT PLACEMENT. Which gates run here is DERIVED
(`medaka gate balance`, #2178) from test/gate_cost_baseline.json and
regenerated into this matrix by `make gen-ci`; it changes whenever the
baseline does, so nothing below names a gate. What this row is:

full_cores = false, wasm_arm = false -> an ordinary shared runner with
no extra toolchain, fully open to the packer. It can take any gate that
does not require the Wasm toolchain, and the balancer fills it to the
same target load as every other open row.

The row NAME is a required status-check context (`gates (eval)`), so
renaming it is a ruleset change, not an edit here — and it carries no
thematic meaning: rows are filled by measured cost, never by theme.
