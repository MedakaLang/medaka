## WHY THIS FIXTURE EXISTS WHERE IT DOES -- A RE-POINT, NOT A DELETION

The must-fail pin above DRAINED when this defect was fixed. AGENTS.md's drain protocol
prefers RE-POINTING a drained pin at a regression gate over deleting it, because a drained
fixture is not a drained CLASS, and deleting removes the only executable memory that the
shape was ever broken. Re-pointing also RECOVERS coverage here, exactly as that protocol
predicts: the must-fail harness graded ONE verb (`check-json`, on `diag-code` + range) in
ONE import order; this gate grades `check` + its diagnostic codes + the inferred schemes +
`run` + `build` + the EXECUTED BINARY, across EVERY ordering. The second dimension the pin
carried -- the other import order -- was sitting there ungraded, and starts executing here.
