what: a module that NAMES one `Cfg` and HOLDS a value of another answers the same in EVERY import-clause order

`main` NAMES armod's `Cfg` as a type (through the re-exporter) and separately HOLDS a value
of zrmod's `Cfg`, whose type it never names. Correct answer: `5`.

here rather than in a closed issue nobody will open:
